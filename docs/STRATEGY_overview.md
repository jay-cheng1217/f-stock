## 一、兩層結構(最重要,別混淆)

系統有兩層,評估與操作分開:

### 1. Champion 自動層
- V2 迴歸預測 20 日超額報酬 → two-stage LambdaRank 重排 → Top30 → 一串硬 gate(流動性/過熱/entry benchmark/市場 regime/TQuant)。
- 產出 `ml/models/unified_signals_<date>.csv`。
- **大市值主導/現金等待 regime 下常為 0 檔**(不是 bug,見 [[feedback-large-cap-bull-market-behavior]])。
- **空池 ≠ 沒候選**;不可用它的空來否定裁量層。

### 2. 裁量短打層(實際在交易的)
- 決策順序:**短打支撐優先 → 本地模型輔助確認 → 明確進場區間 → 籌碼K否決 → 盤中觸發**。
- 模型是**輔助**不是排名主訊號;籌碼K是**否決層**(可直接擋);盤中觸發守 15–30 分才算進場。
- 由 `skills/stock-entry-decision-workflow/SKILL.md` 規範(含資料源、工具、四分級名單)。
- 與朋友「rere」策略同源(見 `docs/rere_strategy.md`);核心 edge 在**籌碼K裁量選股 + 風控**,不在單一時機。

**一句話**:模型池 = watchlist(候選來源),skill = 進場決策紀律(支撐+籌碼優先)。

### 收斂後決策策略(2026-07-01 驗證後,以此為準)

**✅ 已驗證有 edge(保留):**
- **貼MA20(5-10%)+ 不爆量(量比<1.5)+ 法人買** → 勝率 43%→48%、平均報酬也升(6.5 年 12k 筆)。
- **毛利率分真假龍頭**:能扛過景氣寒冬者(聯電/世界 27-30%)可跟;虧一年剛回正者(力積電 10%)避開。
- **外資賣 = 聰明錢警訊**:外資持續倒貨(如力積電 20 日 −23 萬張)不接刀,即使技術低檔。
- **抱 20–60 天**:edge 只在此持有期;短抱/當沖/隔日沖實測皆賠。
- **風控**:賣在壓力、砍支撐破 —— 右尾策略靠此收割。

**❌ 已驗證無 edge(丟掉,別重試):**
- **季末投信做帳(機械化)**:做帳窗投信買超股略負、比季中差,市場 beta 主導。
- **5MA 洗盤當「提高報酬」規則**:20日 洗盤 +2.82% < 追高 +3.64%,只 2022 空頭防禦性勝出;僅適合當「較低進場價+防禦」模式且須配停損。
- **外資買超當進場訊號**:盤後才知、隔天進已大半失效(+1pp),短線可能誤導。
- **投信連買3日當進場條件**(2026-07-02,修復投信資料後驗):60日 +4.28% **劣於** base +7.48%
  ——投信連買=已被看見。可當 watchlist 雷達,不可當扳機。融資減亦無感。
- **TDCC 散戶減(大戶集中)當進場條件**(2026-07-02):與 base 完全相同(+7.29%),週頻太粗
  且一半日子成立=雜訊。rere 篩選器三味全數補驗無機械 edge。

**本質(認清)**:低勝率(4–5成)、靠少數飆股、看市況、電子 beta。edge 在**紀律(不追高+貼支撐+籌碼K否決)+ 抱得住 + 風控**,不在任何單一時機招式。

### 策略排名 = 時點快照(2026-07-02 用戶定調)

**市場不會永遠支持同一種策略;排名需定期重測評分。** 機制:
- `scripts/strategy_scoreboard.py` 重測全部已驗證策略,輸出「全期 vs 近6月」edge 對比
  (`ml/reports/strategy_scoreboard_<date>.md`);已掛進每日排程,**每月 1-3 號自動重跑**。
- 判讀:近期 mean 顯著低於全期(衰減大幅為負)= edge 衰減 → 降權/停用;近期遠高於全期
  = 多頭膨脹,**不可外推**(如 2026-07 快照:近6月多頭讓所有策略 60 日報酬 +25~35%,是
  regime 紅利非策略變強)。
- 新策略驗證通過後須在 scoreboard 註冊,才會被月度重評。
