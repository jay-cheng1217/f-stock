# RESEARCH：斷頭發動型（margin washout ignition）事前登記回測

- 日期：2026-11-12（事前登記 commit 在結果產出之前，見 git 時間戳）
- 來源案例：6456 GIS-KY 深洗盤後三連板（rere 融資倉，docs/rere_strategy.md 結案紀錄）
- 性質：bounded experiment。**研究專用，不改任何 gate；結果達標也只開票送 PM 裁示。**
- 動機：系統驗屍發現兩個缺口——(1) `daily_k.Margin_Balance` 無任何 lane 使用；
  (2) rere 發動型的「站回 MA20＋量比≥1.5＋投信同買」組合在深 V 第一根板結構上必不成立。

## 假設 H1

深洗盤後，「融資斷頭完成＋外資拐點＋當日轉強」同日成立時，後續 10/20 日有正的市場超額報酬。

## 訊號條件（訊號日 t 收盤後全部可得，無前視）

| 代號 | 條件 | 定義 |
|---|---|---|
| A | 深洗盤 | Close_t ≤ 前 10 日（不含 t）最高價 × 0.85 |
| B | 融資斷頭 | Margin_Balance_t / Margin_Balance_{t-10} − 1 ≤ −20%，且 Margin_Balance_{t-10} ≥ 2,000 張 |
| C | 外資拐點 | Σ Foreign_BuySell_{t-5..t-1} < 0 且 Foreign_BuySell_t > 0 |
| D | 當日轉強 | Close_t / Close_{t-1} − 1 ≥ +5% |
| E | 流動性 | VOL_MA_20 ≥ 500 張（與主系統硬擋同口徑） |

**刻意不要求**：站回 MA20、投信同買、量比≥1.5（本實驗的差異點）。

## 量測協定

- 進場：t+1 開盤價；報酬窗：t+5 / t+10 / t+20 收盤（交易日）。
- 超額基準：同訊號日「E 流動性合格」全市場等權同窗報酬（strategy-fit、期初條件口徑）。
- 去重：同一股票兩訊號間隔 < 20 個交易日只取第一個。
- 範圍：2020-02-01 ~ 2026-10-13（外資資料自 2020-01-02 起；尾端保留 20 日 forward）。
- 已知限制：未還原除息（20 日窗噪音可接受）；漲停鎖死日 t+1 開盤可能買不到（回測以 t+1 開盤成交，實務偏樂觀，結果解讀時標注 t+1 跳空幅度分佈）。

## 成功準則（事前登記，不得事後移動）

1. N ≥ 30（去重後）。
2. T+10 或 T+20 平均**超額** ≥ +2pp，且絕對報酬勝率 ≥ 50%。
3. 消融測試：移除 B（只剩 A+C+D+E）時超額需明顯低於全條件組，否則融資面向無增量價值。
4. 附帶統計：全條件訊號中，被現行發動型三個伴隨條件（站回MA20／量比≥1.5／投信>0）擋掉的比例。

## 失敗處置

未達準則 → 封存假設、不開 gate 票、本文件補記結論（永久封存慣例同 MA5 re-entry）。

## 結果（2026-11-12，腳本 `scripts/research_margin_washout_ignition.py`，訊號明細 `ml/reports/research_margin_washout_signals.csv`）

| 組別 | N | T+10 絕對 | T+20 絕對 | T+20 勝率 | T+10 超額 | T+20 超額 | T+20 超額勝率 |
|---|---|---|---|---|---|---|---|
| 全條件 A+B+C+D+E | 383 | +10.72% | +14.76% | 85.6% | +1.16pp | +1.60pp | 44.4% |
| 消融（無 B 融資斷頭） | 1,059 | +4.56% | +6.40% | 63.7% | +0.11pp | +0.16pp | 41.7% |

- t+1 開盤 gap 中位數 −0.16%、>9% 僅 1.8% → 「買不到」問題不大，進場可行性 OK。
- **訊號分佈**：383 個訊號只落在 70 個日期；2020-03（129）＋2025-04（93）＋2021-05（66）＋2024-08（30）＝83% 集中在四個崩盤反彈月。
- fwd20 右偏：>+30% 占 15.9%、<−10% 占 6.0%、中位數 +12.9%、最大 +117%。

## 判定（對照事前準則）

1. N=383 ≥ 30 ✓
2. **FAIL**：T+10 超額 +1.16pp、T+20 超額 +1.60pp，均 < +2pp；超額勝率 44% < 50%。中位超額為負（T+20 −1.32pp）。
3. 消融方向成立：移除 B 後絕對 +14.8%→+6.4%、超額 +1.60pp→+0.16pp → 融資斷頭面向確有增量資訊，但不足以過門檻。
4. 現行發動型伴隨條件在這批訊號上：站回MA20 僅 5% 成立、量比≥1.5 僅 10%、投信同買僅 11%，**三者同時成立 0%** → 結構性互斥確認（深 V 第一根板必然不過現行發動型）。

## 結論與處置

- **封存 H1、不開 gate 票**。驚人的絕對報酬（+14.8%/85.6%）幾乎全是崩盤反彈的市場 beta：
  同日全市場流動池同窗平均約 +13pp，個股層面的選股超額只有 +1.6pp 且中位數為負、靠少數大贏家撐起平均（彩券型分佈）。
  GIS-KY 屬於右尾個案（大盤修正 7,083 點後的反彈段），此型訊號「抓得到它」但抓到的典型標的只是跟著大盤彈。
- 對「系統為什麼沒抓到 GIS」的最終回答：缺的不是個股 gate，而是**市場層級的崩後反彈時機**——Champion 本來就定位為中小型動能系統、不做抄底擇時，此 miss 屬設計取捨而非缺陷。
- 待驗證假設（未開票，僅記錄）：融資斷頭的**廣度**（全市場符合 B 的家數/占比）或可作為「崩後反彈 regime 指標」研究題——
  是市場擇時假設，與本實驗的個股選股假設不同，須另行事前登記。
- 融資餘額變化作為**模型特徵**（而非 hard gate）的價值，留待下一輪 V2 重訓的特徵實驗評估（需 PM 核可重訓時一併提出）。
