# Canonical entry artifact lineage: method lock

The confirmed defect is a same-date stale plan: DataA can successfully publish new certified scores while a later generator fails, leaving an older date-only entry plan. A renderer must not combine those artifacts. The only change is artifact provenance and publication/consumption validation. The complete raw `generate`, technical/pattern/rere predicates, ranking, and score calculations remain AST-identical. Frozen research outputs remain unchanged.

Add `generate_certified` around the existing generator. Before its actual publishable generation, capture the selected prediction CSV and certificate, the verified canonical snapshot and certificate, the canonical source signature/full source receipts, and actual additional readers: sector/name mapping, sector strength, disposition report/periods/corrections, watchlist, disposition radar, announcements, TWII, calendar overrides, relevant source code, and enabled ChipK files/environment. Afterwards require unchanged sources/dependencies, still-valid selected prediction/snapshot, and unchanged prediction selection before binding the actual returned result. A failed generation does not create evidence.

Generation runs exactly once. The existing CLI's authorized watchlist writes are captured narrowly around the actual `Path.write_text` calls for watchlist/archive, recording the pre-write input and expected written bytes. Only those observed authorized outputs may differ after generation; all other inputs must remain unchanged. The certificate preserves the original watchlist evidence and readers require the recorded post-write state. The read-only rebuild has no such exception. The raw generator stays available for isolated research. A live-night quote is recorded only as the observation in the actual result, never claimed to be a reproducible file input or a verified intraday trigger.

`to_entry_json` may convert a certified result into a payload carrying compact lineage plus an internal publication certificate. The atomic publisher requires that certificate, binds the exact JSON bytes, and publishes a sidecar. It cannot certify a pre-existing JSON plan. Readers verify the pair, current source/extra dependency state, selected prediction and snapshot bytes/certificates, and source/trade-date validity. Missing, changed, historical, or incomplete pairs raise a clear data error rather than returning empty candidates. The loader returns the verified payload from the bytes whose SHA was checked.

Acceptance: focused temporary-source fixtures must reject legacy payloads, same-date score replacement, auxiliary/extra dependency changes, changed selection, corrupted/missing sidecars, failed generation and changed inputs during generation. Successful generation/publishing/loading must preserve candidate values and both static/log copies. AST equality must hold for the complete generation/strategy functions. Root then performs a real certified generation from the already scored inputs and compares the same 18 candidates / 6 rere names; no new model inference or threshold changes are required.

Integration: the production CLI now calls `generate_certified`; `smart_update_auto` already invokes that CLI, so no nightly strategy edit is needed. The formal auditor reads the trusted payload and checks plan/sidecar receipts before and after, adding `entry_plan_lineage`. Renderer and app integration are owned by their respective agents and use the same `load_entry_artifact(path)` error contract. Earlier ignored drivers using raw `generate` are provenance of their original runs; the final rebuild must use the updated runbook and a new receipt filename.

Default-date acceptance: both CLI and certified wrapper use the most recent completed close (a trading day becomes completed at 18:00), then its next trading day. The wrapper passes the captured explicit dates to the single raw generation; raw research defaults remain unchanged. Clock fixtures cover Friday 17:59/18:00, weekend, and Monday morning/17:59/18:00, including actual temporary certified generation without date arguments.
