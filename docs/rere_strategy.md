## 核心一句話

**籌碼K 選股(投信照顧 + 主力成本)＋ 絕不追高 ＋ 等主力洗回 5MA/支撐才進 ＋
波段賣壓力 ＋ 主題族群留基本倉。**

## 六大要素

1. **絕不追高,等主力殺回 5MA**
   - 原話:「如果我是主力,現在一定殺回 5ma 嚇跑追高的人」「112 是壓力了怎麼會買漲停追高」
   - 進場只在**拉回支撐**時,噴出/漲停一律不追。

2. **波段操作:賣在壓力、回落再玩**
   - 例:某股 106→155 波段「幾乎出光,繼續等機會再玩一次」。同一檔反覆做波段。

3. **玩轉機/低基期股(可虧損但營收要成長)**
   - 例(鈦昇):當時「2 月合併虧損 1400 萬、EPS −0.12」,但營收 135(去年 83)成長 → 照做波段。

4. **主題/族群佈局 + 留基本倉**
   - 2026 主題點名:**封裝封測**。「基本倉必須留好」,強勢主力股抱到千金。

5. **重度依賴籌碼K**
   - 季末投信做帳 → 玩「有投信照顧」的股票。
   - 用籌碼日報拉「主力成本」在哪;用籌碼K「健檢」去蕪存菁(尤其盤勢不好時)。
   - 健檢看:技術趨勢、大股東籌碼集中/分散、外資投信買賣、長期存股/波段價值/短線價差 %。

6. **盤勢不好更靠籌碼篩**,寧可少做、等機會。

## 篩選器配方(2026-07-02 限動首次公開)

rere 的籌碼K篩選條件:投信連續3日買超、外資連續3日買超、自營連買、持股100張以下
比例減少(散戶減=大戶集中)、融資減;技術面:剛站回5MA、回踩月線/季線;輔以KD/MACD/量。
**關鍵語**:「主重籌碼——法人連買但還沒起飛的」「不可能全買,加入清單做觀察」。

**補驗判決(2026-07-02,修復投信資料後)**:投信連買3日機械化當進場條件**無 edge 且為負貢獻**
(60日 +4.28% vs base +7.48%);融資減無感;組合最差。原因:投信連買=已被看見,右尾在未被
發現的股票。**她的真實用法=篩選器當「雷達」建觀察清單,進場扳機是「買在投信進場前」的
裁量蹲點** —— 雷達≠扳機,機械化把雷達當扳機必然失敗(與季末做帳/外資買超/5MA 同構教訓)。
系統對應:投信連買可作 watchlist 掃描來源;進場仍走 rere lane(洗盤+外資轉買+貼支撐)。
**三味補驗全收官(2026-07-02)**:投信連買3日=負貢獻(-3pp)、融資減=無感、TDCC散戶減
(大戶集中,週頻+公布時滯4天)=與base完全相同(+7.29% vs +7.29%)。三次同構結論:
篩選器每一味機械化皆無alpha,rere的edge 100%在裁量(挑哪檔+買在投信前+洗盤時機),
該編碼的已在 rere lane。

## 回測驗證(2026-07-01,重要)

用專案資料機械化驗證 rere 幾個要素,結論:**她的招機械化多半沒 edge,真 edge 在
裁量選股(籌碼K)+ 風控,不在單一時機。**

- **季末投信做帳:❌ 無 edge。** 做帳窗(季末最後10日)投信買超股平均 −1.31%、比賣超
  (−0.90%)還差,也比季中(+0.4%)差;逐季極不穩(2025Q1 −9%、2026Q1 −6.8%),本質是
  市場 beta。→ 不編碼。
- **5MA 洗盤後進:⚠️ 原始報酬無 edge。** 20日持有:5MA洗盤 +2.82% < **追高(不洗)+3.64%**,
  只在 2022 空頭洗盤才勝出(防禦性)。機械化「等洗盤」不提高報酬(多頭追高還更賺);
  洗盤的價值是**較低進場價+空頭少賠**,但需**配停損/出場紀律**才發揮(回測純持有抓不到)。
  → 不當「提高報酬」規則編碼;若用,定位為防禦+較佳進場價模式。
- **共同教訓**:rere 厲害在**用籌碼K挑「哪一個」洗盤/投信照顧股 + 賣在壓力的風控**,
  機械化「全部進」會把 edge 稀釋掉。單一時機(5MA/季末)本身不是 alpha。
