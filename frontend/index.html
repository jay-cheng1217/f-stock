操作指引

每日只看兩條線：Champion 自動主軌與大票法人手動覆蓋層。
Champion 主系統（自動）
開盤前：要不要買
  1. 開 進場推薦 頁籤，看今日有沒有新訊號
  2. 訊號的 two_stage_rank ≤ 30（排名越小越好）
  3. 同一供應鏈族群持倉 ≤ 2 檔（避免集中風險）
✔ 以上全過 → 開盤依訊號買進
✘ 任何一項未過 → 今天不動，等明天重新評估
收盤前：要不要出場（每日查持倉）
MA5_BREAK 當日收盤跌破 5 日均線 → 收盤出場
HWM −8% 從持有最高點回落 8% → 收盤出場
20D 到期 持滿 20 個交易日 → 強制出場，不等了
無觸發 以上皆無 → 繼續持有，明天再查
手動覆蓋層（大票）
要不要買（2330 / 2454 / 2308）
  1. 查個股法人明細：外資連續買超 ≥ 3 個交易日
  2. 當日收盤價 站上 20 日均線（MA20）
✔ 兩項都達到 → 進場，單檔部位 ≤ 20%，最多同時持 2 檔
✘ 任何一項未達到 → 不進場，繼續觀察
要不要出場（持倉中每日查）
連賣訊號 外資連續賣超 ≥ 2 個交易日 → 收盤出場
無訊號 連賣未達 2 日 → 繼續持有
